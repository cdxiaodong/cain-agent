## 5. 回滚预案

- tag 推送后发现缺陷:`git tag -d v0.2.1 && git push origin :refs/tags/v0.2.1`,
  GitHub Release 先 `gh release delete v0.2.1`;修复后重新走 ④⑤
- 版本号误 bump 未打 tag:revert 提交即可,无远端影响
