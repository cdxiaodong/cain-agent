test 会话共有 8 个 error tool result，其中 7 个为 scope 拒绝，1 个为无法提取目标后的默认拒绝。典型误拦包括：

```text
目标不在授权范围内: POST
目标不在授权范围内: GET
目标不在授权范围内: /api/wishes
无法从 Bash 命令中提取出有效的目标 host（默认拒绝）
```

根因确认：`ScopeGuardHook` 解析 curl 命令时，把 HTTP method 值 `POST`、`GET`，以及 `--request-target` 的路径值当作网络目标。只要同一命令里出现任一误抽取目标，整个命令会被拒绝，导致真实授权 URL 也无法执行。

## Scope 修复

修改 [scope.py](../src/cain_agent/scope.py)，把以下 curl 参数加入值参数列表，避免其参数值被当作网络目标：

```text
-X
--request
--request-target
```

新增两条回归测试：

- `-X POST` 不再被抽取为目标 host
- `--request-target /api/wishes` 不再被抽取为目标 host
