# 开发节奏政策(用户指令 2026-10-09)

> **用户原话:"降低开发频率 现在垃圾代码太多了"**——立即生效。

## 新节奏

- **暂停 Phase 5 新功能开发**(C3/C4/D/E 全部冻结,不出单不领取),
  直至用户明确重启。
- 日更目标从「每天 ≥6 commit」**降为「每周 2-3 个高质量 commit」**;
  断流不再记失职、不再补位冲量。
- 巡查班次保留但只做**状态记录**,无实质交付的日子不强行造 commit
  (空转的日报本身就是噪音)。

## 下一步方向(等用户点名再做)

优先做**质量收口**而非新功能:

1. **垃圾代码清理**:盘点 Phase 5 期间新增的 12 个模块,凡「为通过
   测试而写、无真实调用方、纯流程装饰」的代码标记删除候选,列清单
   请用户勾选;
2. **真实闭环验证**:已堆了很多纯函数层(patchdiff/scout/bac),
   挑一条在真实授权目标上端到端跑通(而非继续加层);
3. v0.2.1 发版收口(67+ commit 积压含安全修复,越拖越大)。
