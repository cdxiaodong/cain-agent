# Cain 演示视频分镜脚本(3 分钟)

> 用途:录制 Cain 第一支演示视频。时长约 3 分钟,节奏紧凑,每镜配旁白文案 + 画面说明。
> 数据约定:全程使用本地靶场(127.0.0.1)与自有账号靶场,不出现真实目标信息。
> 录制前确认:`cain-agent run` 子命令已可用、vuln-tf 靶场画面已录屏备用。

## 分镜表

### 镜 1 · 痛点引入(0:00 - 0:20)

**画面**:黑屏白字打字机效果,逐行出现以下文案;最后一行定格 2 秒。

**旁白文案**:
> "市面上的 AI 渗透工具,大多数跑的是静态靶场、找的是预设 flag。
> 真实授权评估里,你要对付的是业务逻辑缺陷、云配置错误、以及一个根本问题——
> AI 报的漏洞,你敢直接交付吗?"

**转场**:字幕"Cain — 实战型 AI 渗透工程师"淡入,logo 停留。

---

### 镜 2 · 安装与启动(0:20 - 1:00)

**画面**:终端全屏(深色主题,字号放大)。依次输入命令,每条命令后停顿展示输出。

**操作序列**:

```bash
pip install cain-agent          # 安装,展示进度条走完

cain-agent --version             # 确认版本号

cain-agent run --target 127.0.0.1 --workspace ./demo-ws --dry-run
# dry-run:初始化 workspace + scope,打印执行计划,不起 Agent
```

**旁白文案**:
> "一条命令安装。dry-run 模式先初始化工作区和 scope 白名单,打印执行计划给你确认——
> 默认只放行 127.0.0.1,scope 由配置强制执行,不是靠 AI 自觉。
> 确认无误后去掉 --dry-run,编排循环正式开始。"

**画面标注**:scope.yaml 内容高亮闪烁,强调 `in_scope: [127.0.0.1]`。

---

### 镜 3 · 编排循环跑动 + 校验闭环产物(1:00 - 2:00)

**画面**:终端分屏——左侧实时滚动编排循环日志,右侧固定展示 workspace 目录树。循环按 recon → test → report 三阶段推进。

**展示要点**:
1. 日志出现 `[stage] recon →` → 右侧 `demo-ws/recon/` 目录出现 endpoints 草稿;
2. 日志出现 `[stage] test →` → 右侧 `demo-ws/findings.json` 出现,高亮初始状态 `validation_inconclusive`;
3. 日志出现 `[stage] report → 校验流水线介入` → 右侧 `demo-ws/report/validation-summary.json` 出现,高亮各状态计数(confirmed / false_positive / inconclusive / system_error)。

**旁白文案**:
> "循环是确定性状态机——recon、test、report 三个阶段硬编码,不能跳序。
> 每条发现初始都是'待校验'状态。报告生成前,校验流水线用独立会话逐条复核——
> 发现 Agent 和校验 Agent 不是同一个,谁也不能既当运动员又当裁判。
> 注意所有输出都过了脱敏 Hook:就算 Agent 带回了凭证,落盘的也只是哈希。"

**画面标注**:findings.json 中一条发现的 `status` 从 `validation_inconclusive` 变为 `confirmed` 的过程用箭头动画标注。

### 镜 4 · 云模块演示(2:00 - 2:40)

**画面**:左右分屏。

- **左半屏**:OSS 暴露检测模块输出(靶场桶画面,桶名已脱敏为 example-bucket-*)。
  展示:靶标桶 public-read → 定级 high;对照桶 private → 定级 info。
- **右半屏**:RAM 提权路径分析模块输出(靶场用户画面,用户名已脱敏为 vuln-ram-user-demo / safe-ram-user-demo)。
  展示:靶标用户命中 2 条 critical 提权路径;对照用户零命中。

**旁白文案**:
> "这是 Cain 最独特的部分——国产云安全检测。
> OSS 模块只读检查桶的 ACL,定级规则是代码常量,公开可写就是 critical,不是模型拍脑袋。
> RAM 模块枚举用户权限,匹配提权路径规则表——这个用户能给自己挂策略、能为别人造 AccessKey,两条 critical 路径全部命中。
> 这些靶场是我们自建的 vulnerable-terraform,专门给这两个模块做端到端回归。"

**画面标注**:靶标 vs 对照的检测结果并排对比,用红/绿色标注。

## 录制注意事项

1. **凭证安全**:全程不出现真实 AccessKey、Token、密码。所有云演示画面使用 vuln-tf 靶场,靶标名已脱敏。
2. **scope 真实性**:dry-run 画面里 scope 只含 127.0.0.1,录制时确保终端环境干净。
3. **字幕同步**:旁白文案建议后期配音 + 字幕,不实时口播,避免口误泄露信息。
4. **节奏**:每镜控制在标注时长内,总时长不超过 3 分 10 秒。镜 3 是信息密度最高的一段,可适当放慢。
5. **法律**:视频结尾叠加授权测试声明文字(停留至少 3 秒)。
